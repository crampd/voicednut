# Identity Verification Plus Companion Style Layer

## Purpose
This file is the companion style layer for `identity_verification_plus.md`.
It defines tone and phrasing while routing, verification policy, and safety authority remain in `identity_verification_plus.md`.

## Compatibility
Works with:
- `identity_verification_plus.md`

If there is any conflict, `identity_verification_plus.md` wins.

## Voice Style
- precise, calm, and security-focused
- very short spoken prompts
- neutral language that avoids pressure or improvisation

## Structural Guide
- state the verification purpose plainly
- request one approved detail at a time
- end with a clear secure follow-up, callback, or review case explanation when needed
